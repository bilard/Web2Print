# DESIGN.md — IBS-Studio (promo social verticale)

## Identité
Plateforme B2B dark mode qui orchestre le pipeline catalogue → créa → print → digital.
Ton : pro, dense, technique. Inspiré Linear / Vercel / Stripe. Pas Canva, pas de superlatifs.

## Typo
Stack système : `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`.
Métadonnées en monospace : `ui-monospace, "SF Mono", monospace`.
Poids 400 corps, 600 label, 800 titres. Letter-spacing tight sur les hero (`-0.03em`).

## Mood
- Surfaces plates + bordures translucides. Glow indigo/accent discret mais VISIBLE (vidéo).
- Grain léger + grille fine sur les fonds. Pas de gradients hype plein cadre.
- Mouvement ease-out cubique, 0.3–0.8s. Pas de bounce. Chaque décoratif a un mouvement ambiant.

## Tone of voice
Court, dense, descriptif. Verbes : orchestre, centralise, scrape, structure, enrichit, génère, décline, exporte.
Éviter : révolutionnaire, magique, incroyable.
